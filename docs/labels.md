# Labels 功能清单（产品视角）

> Label 是 workspace 级别的标签：每个标签有**名字**和**颜色**，可以贴到任意数量的
> issue 上，一个 issue 也可以贴多个标签。团队用它给 issue 做分类、标记主题，
> 再按标签筛选和分组，快速找到一类工作。

这是一份自顶向下、面向用户能力的功能清单，用来核对产品功能是否齐全。

## 1. Label 是什么

- [ ] 用户可以在 workspace 里创建标签：给它起一个名字、选一个颜色。
- [ ] 标签属于整个 workspace，所有成员共用同一套标签库。
- [ ] 同一个标签可以贴到很多 issue 上；一个 issue 也可以同时有多个标签（多对多）。
- [ ] 标签在界面上以彩色小圆点 + 名字的形式展示，颜色一眼可辨。

## 2. 管理标签（创建 / 编辑 / 删除）

- [ ] **创建**：填写名字并从一组预设颜色里挑一个，即可新建标签。
  - [ ] 名字和颜色都是必填，缺一不能创建。
- [ ] **编辑**：随时改标签的名字或颜色；改动会同步反映到所有贴了该标签的 issue。
- [ ] **删除**：删除一个标签会把它从所有 issue 上一并移除，且不可撤销。
  - [ ] 删除前会有确认提示，说明它将从所有 issue 上被移除。
- [ ] 标签列表统一在设置区集中管理，列出当前 workspace 的全部标签。
- [ ] 没有任何标签时，列表显示引导用户去创建第一个标签的 empty state。

## 3. 给 issue 贴标签

- [ ] 在 issue 上打开标签选择器，勾选要贴的标签、取消勾选要去掉的标签。
- [ ] 可以一次给一个 issue 设置多个标签，保存后即时生效。
- [ ] 标签选择器内可按名字搜索，快速定位想要的标签。
- [ ] 如果搜不到想要的标签，可在选择器里**就地新建**一个标签（顺便挑颜色），新建后立即贴到当前 issue 上。
- [ ] 在 issue 上可以直接移除某个已贴的标签。
- [ ] 创建 issue 时也能直接为其指定标签。
- [ ] issue 详情页和列表行都会展示该 issue 当前的标签；数量过多时会折叠显示（如只显示前几个，其余以「+N」表示）。
- [ ] 标签变更会实时同步给团队其他成员，无需刷新页面。

## 4. 用标签组织工作

- [ ] **按标签筛选**：在 issue 列表里按一个或多个标签过滤，只看带某些标签的 issue。
- [ ] **按标签分组**：把 issue 列表按标签分组展示。

## 5. 权限与 workspace 隔离

- [ ] 标签按 workspace 隔离：每个 workspace 有自己独立的一套标签，互不可见、互不影响。
- [ ] 只能给本 workspace 内的 issue 贴本 workspace 的标签。
- [ ] 创建、编辑、删除标签，以及给 issue 贴 / 取消标签，都仅限该 workspace 的成员。
